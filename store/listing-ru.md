# Листинг Chrome Web Store — Русский

## Название (макс. 45 символов)
Speed Up ChatGPT — Lag Fix & Chat Export

## Краткое описание (макс. 132 символа)
Уберите лаги ChatGPT в длинных чатах: рендерятся только последние сообщения. Экспорт чатов в PDF, Markdown, TXT, JSON.

## Категория
Продуктивность (Productivity)

## Подробное описание
ChatGPT тормозит, лагает или зависает в длинных диалогах? Speed Up ChatGPT решает это в один клик.

ПОЧЕМУ CHATGPT ТОРМОЗИТ
Каждое сообщение диалога остаётся на странице. После 100+ сообщений вкладка становится тяжёлой: скролл дёргается, ввод текста лагает, расход памяти растёт, вкладка может зависнуть полностью.

РЕШЕНИЕ
Расширение обрезает диалог до последних N сообщений ДО того, как ChatGPT его отрисует. Ничего не удаляется — вся история остаётся на сервере — браузер просто не рендерит сотни старых узлов. Длинные чаты снова работают быстро.

ВОЗМОЖНОСТИ
• Мгновенное ускорение длинных диалогов ChatGPT
• Настраиваемый лимит: 5–200 видимых сообщений
• Кнопка «Load more» подгружает старые сообщения порциями, позиция скролла сохраняется
• Живая статистика: видимые / скрытые / всего сообщений
• Экспорт любого чата в PDF (аккуратная печатная вёрстка), Markdown, TXT или JSON
• Тихий режим без уведомлений
• 100% приватность: без аккаунтов, аналитики и сбора данных — всё работает локально
• Открытый исходный код (MIT)
