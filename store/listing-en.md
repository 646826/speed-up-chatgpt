## Detailed description
Is ChatGPT slow, laggy or freezing in long conversations? Speed Up ChatGPT fixes it in one click.

WHY CHATGPT LAGS
Every message of a conversation stays on the page. After 100+ messages the tab becomes heavy: scrolling stutters, typing lags, memory usage explodes, the tab can freeze completely.

THE FIX
The extension trims the conversation to the latest N messages BEFORE ChatGPT renders it. Nothing is deleted — your full history stays on the server — your browser simply stops rendering hundreds of old nodes. Long chats become fast again instantly.

FEATURES
• Instant speed boost for long ChatGPT conversations
• Adjustable limit: keep 5–200 recent messages visible
• "Load more" button reveals older messages in batches, scroll position preserved
• Live stats: visible / hidden / total messages
• Export any chat to PDF (clean print layout), Markdown, TXT or JSON
• Quiet mode: no notifications
• 100% private: no accounts, no analytics, no data collection — everything runs locally
• Open source (MIT)

PERFECT FOR
Power users, developers, researchers and anyone whose ChatGPT chats grow long enough to slow the browser down.
