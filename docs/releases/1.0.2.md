# Speed Up ChatGPT 1.0.2

## What's new
- Export and statistics stay attached to the currently open conversation when switching quickly between chats.
- Late responses from another conversation no longer replace the current export snapshot.
- Loading older messages ignores duplicate clicks while settings are being saved.
- Failed preference reads or saves leave the page intact and allow a retry instead of a pointless reload.
- A late save does not reload a different conversation opened in the meantime.

## Что нового
- Исправлен выбор переписки для экспорта и статистики при быстром переключении разговоров.
- Запоздалый ответ другого разговора больше не подменяет текущие данные.
- Повторные нажатия загрузки старых сообщений не создают несколько операций.
- При ошибке чтения или сохранения настроек страница не перезагружается; попытку можно повторить.
- Завершение старого сохранения не перезагружает уже открытый другой разговор.

## Release scope
Includes merged PRs #5 and #6 and all changes from 1.0.1. No new permissions, dependencies or settings.
The combined release must pass all existing regression suites and the ZIP build. No authenticated live-chat verification or measured end-to-end speedup is claimed.
Normal Chrome Web Store review is required. Submission, approval and public availability are separate states; inspect the release evidence. Existing pending submissions are not cancelled automatically. The listing description is not updated by the package API.
