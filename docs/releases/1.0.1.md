# Speed Up ChatGPT 1.0.1

## What's new
- Improved compatibility with conversation requests that use relative URLs, URL objects or query parameters.
- Saved preferences now reach the running interceptor after startup, including when page storage is blocked. Older startup responses no longer overwrite newer settings.
- More robust Markdown, text and print-preview exports when conversation node IDs are missing or repeated.
- Readable filenames for Russian and other non-Latin conversation titles.
- Additional regression coverage for export fidelity, settings and request handling.

## Что нового
- Улучшена совместимость с разными форматами запросов загрузки переписки.
- Сохранённые настройки надёжнее применяются после запуска и не перезаписываются запоздалыми ответами.
- Исправлена обработка отсутствующих или повторяющихся идентификаторов сообщений при экспорте.
- Названия разговоров на русском и других языках сохраняются в именах файлов.
- Расширены автоматические проверки экспорта и настроек.
